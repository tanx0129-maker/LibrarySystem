# 图书借阅管理系统需求分析

## 1. 项目目标

开发一个基于 C++ 的图书借阅管理系统，实现图书信息、用户信息和借还书记录的管理。

## 2. 用户类型

系统暂时包含两类用户：

- 学生
- 教师

用户信息包括：

- 用户编号
- 姓名
- 院系
- 最大借阅数量

## 3. 图书信息

图书信息包括：

- ISBN
- 书名
- 作者
- 出版社
- 是否可借

## 4. 核心功能

第一阶段实现：

1. 添加图书；
2. 删除图书；
3. 修改图书信息；
4. 查询图书；
5. 添加用户；
6. 借书；
7. 还书；
8. 判断图书是否逾期；
9. 计算逾期罚款；
10. 保存和读取数据。

## 5. 第一阶段暂不实现

以下功能暂时不做：

- 图形界面；
- 数据库；
- 网络登录；
- 多用户同时操作。
